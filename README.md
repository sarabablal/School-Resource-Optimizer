# School Resource Optimizer 

A Python tool that analyzes official Moroccan Ministry of Education statistics to flag which education categories (level × sector) are most overcrowded, based on the students-per-classroom ratio — helping decision-makers see where classroom pressure is worst.

## Why This Matters

Many students in Morocco lack basic resources — desks, textbooks — and get stuck in that gap for years, learning in conditions that don't match what the country is capable of. This project is a small step toward making that gap visible, so resources can actually reach where they're needed most.

## The Problem

The Ministry of Education publishes national statistics every year, but as raw numbers in a report, it's hard to instantly see which part of the system is under the most pressure. This project turns that report into a clear, ranked priority list.

## A Note on the Data

The official Ministry file (`statistique_2024-25_VF.xlsx`) does **not** contain per-school data — it only has numbers aggregated at the national level, split by education level (Primaire / Collégial / Qualifiant) and sector (Public / Privé). So instead of ranking individual schools, this project ranks **categories** (e.g. "Collégial Public"), using the students-per-classroom ratio as the crowding indicator.

## How It Works

1. **Data extraction** (`exploration.py`) — downloads the official Ministry Excel file (or falls back to a local backup copy if the download fails), pulls out the relevant numbers, and saves them as a clean CSV.
2. **Modeling** (`src/school.py`) — each category is represented as a `Category` object that computes:
   - Students per classroom (`students / rooms`)
   - Status: `Overcrowded`, `Balanced`, or `Light Load`
3. **Optimization** (`src/optimizer.py`) — loads all categories from the processed CSV and partitions them into overcrowded / light load / balanced groups.
4. **Report** (`main.py`) — prints a summary report to the terminal, with a prioritized list of the most overcrowded categories.

## Project Structure

```
school-resource-optimizer/
├── data/
│   ├── backup_statistiques.xlsx   # local backup of the ministry file (used if live download fails)
│   ├── processed_schools.csv      # generated by exploration.py
│   └── status_chart.png           # generated by visualize.py
├── src/
│   ├── __init__.py
│   ├── school.py          # Category class: ratio and status logic
│   └── optimizer.py       # ResourceOptimizer: loads data, partitions categories
├── exploration.py         # downloads & prepares the raw Ministry dataset
├── main.py                # entry point — runs the full text report
├── visualize.py            # generates the bar chart
├── requirement.txt
└── README.md
```

## Installation

```bash
git clone https://github.com/sarabablal/school-resource-optimizer.git
cd school-resource-optimizer
pip install -r requirement.txt
```

## Usage

```bash
# Step 1: download and prepare the data
python exploration.py

# Step 2: run the analysis
python main.py
```

## Sample Output

```
MOROCCAN EDUCATION RESOURCE EVALUATION REPORT
Total Categories Evaluated : 6
🔴 Overcrowded             : 1
🟡 Light Load              : 3
🔵 Balanced                : 2

OVERCROWDED CATEGORIES (HIGH PRIORITY):
  - [2] Collegial Public   | Students: 1943201  | Rooms: 46305  | Students/Room: 42.0
```

Public collégial classrooms average **42 students per room** — the highest pressure point in the whole system, while private-sector classrooms across all levels stay under 20 students per room.

![Students per classroom by category](data/status_chart.png)

## Visualization

`visualize.py` reuses the same data pipeline as `main.py` to draw a bar chart instead of a text report — red bars are overcrowded categories, orange is balanced, green is light load.

```bash
pip install matplotlib
python visualize.py
```
